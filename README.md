# باشگاه آنلاین ارسلان دوجو 🥋

دو سایت کامل برای یک باشگاه رزمی:

| # | سایت | آدرس | ورود |
|---|------|------|------|
| ۱ | **پنل مربی** (مدیریت باشگاه) | `http://localhost:4173` | `arsalan` / `arsalan123` |
| ۲ | **پنل شاگردان** (بچه‌های باشگاه) | `http://localhost:4174` | `ali` / `123456` |

هر دو سایت به **یک دیتابیس مشترک** وصل هستند؛ پس هر شاگردی که در سایت دوم ثبت‌نام کند،
بلافاصله در پنل مربی دیده می‌شود و برعکس.

---

## اجرا

نیاز به Node.js نسخه ۲۲.۵ یا بالاتر. **هیچ `npm install` برای اجرای سایت لازم نیست**
(بدون وابستگی بیرونی؛ دیتابیس از ماژول داخلی `node:sqlite` است).

```bash
npm start            # هر دو سایت با هم
# یا جدا:
npm run start:coach
npm run start:members
```

تست خودکار (هر دو سرور باید در حال اجرا باشند):

```bash
npm i --save-dev jsdom   # فقط برای تست
npm test
```

## امکانات سایت ۱ — پنل مربی

- **داشبورد**: آمار شاگردان، تمرین‌های تکمیل‌شده، خودارزیابی‌ها، نمودار میانگین نمره باشگاه در ۱۲ ماه.
- **شاگردان**: فهرست، جستجو، فیلتر کمربند، ثبت شاگرد جدید، ویرایش، بازنشانی رمز، حذف،
  و «ورود به پنل شاگرد» (باز کردن سایت دوم با هویت آن شاگرد).
- **تمرینات**: ساخت برنامه تمرینی با دسته، سختی، مدت و مهلت شمسی؛ ارسال به یک/چند/همه شاگردان؛
  دیدن وضعیت انجام هر نفر؛ نوشتن **بازخورد** که برای شاگرد اعلان می‌شود.
- **جدول پیشرفت**:
  - *جدول ماهانه یک شاگرد*: ۱۲ ماه × شاخص‌های «جلسات، استقامت، قدرت، تکنیک، انعطاف، انضباط، وزن»
    با ذخیره خودکار و نمره کل خودکار.
  - *نمای کلی باشگاه (سالانه)*: جدول حرارتی همه شاگردان × ۱۲ ماه + میانگین باشگاه.
  - خروجی **CSV** برای اکسل (با BOM، فارسی درست نمایش داده می‌شود).
- **اطلاع‌رسانی**: انتشار اطلاعیه (سراسری یا برای افراد مشخص، قابل سنجاق کردن)،
  پیام مستقیم به شاگرد، و صندوق رویدادهای دریافتی (ثبت‌نام جدید، تکمیل تمرین، خودارزیابی).

## امکانات سایت ۲ — پنل شاگردان

- **ثبت‌نام و ورود** با ذخیره دائمی در دیتابیس (اطلاعات با ری‌استارت سرور پاک نمی‌شود).
- **پنل کاربری شخصی**: تمرینات من (شروع کردم / انجام شد + یادداشت برای مربی)،
  جدول پیشرفت ماهانه و سالانه، اطلاعیه‌های باشگاه، اعلان‌های شخصی، ویرایش پروفایل و تغییر رمز.
- **خودارزیابی ماهانه**: شاگرد تعداد جلسات و وضعیتش را ثبت می‌کند تا مربی در جدول منظور کند.

## ساختار پروژه

```
shared/          هسته مشترک
  db.js          اسکیم + توابع دیتابیس (SQLite)
  seed.js        داده نمونه (مربی، ۸ شاگرد، تمرین، جدول پیشرفت، اطلاعیه)
  jalali.js      تبدیل تاریخ شمسی ↔ میلادی
  server.js      مسیریاب/سرور HTTP کوچک بدون وابستگی
  public/ui/     CSS و JS مشترک هر دو سایت
coach/           سایت ۱ (server.js + public/)
members/         سایت ۲ (server.js + public/)
data/            فایل دیتابیس (خودکار ساخته می‌شود، در گیت نمی‌رود)
tests/ui-smoke.js تست خودکار رابط کاربری با jsdom
```

## داده‌ها کجا ذخیره می‌شوند؟

`data/arslan-dojo.db` (SQLite، حالت WAL). رمزها با `scrypt` + نمک تصادفی هش می‌شوند و
کوکی نشست `HttpOnly` است. برای شروع از صفر: `npm run reset-db` و بعد اجرای دوباره.

## نکته‌ها

- همه تاریخ‌ها شمسی هستند (الگوریتم jalaali، بدون کتابخانه خارجی).
- برای تغییر پورت‌ها: `COACH_PORT=5000 MEMBER_PORT=5001 npm start`.
- فایل `index.html` در ریشه مخزن، یک صفحه قدیمی و بی‌ربط (NEXUS) است و به این پروژه مربوط نیست.
