# Local Vazirmatn font

Source: `@fontsource-variable/vazirmatn@5.3.0`, downloaded from the npm registry.
Upstream: https://github.com/rastikerdar/vazirmatn
License: SIL Open Font License 1.1; see `OFL-Vazirmatn.txt`.

The three unmodified variable WOFF2 subsets (Arabic/Persian, Latin, extended Latin)
cover weights 100–900. `vazirmatn.css` is the package stylesheet with relative local
URLs and the existing app family name `Vazirmatn`. No runtime npm dependency or
third-party font request is needed. The academy page resolves the stylesheet and
fonts relative to its same-origin mount (`/`, `/coach`, `/member`).
